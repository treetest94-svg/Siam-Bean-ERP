# Team handover

The course requires genuine team participation and commits from each member. Names and contributions were not supplied, so they have not been invented.

Before submission:
1. Add the actual team name, member names/IDs only where your course requires them; avoid personal identifiers in the public repo unless every member agrees.
2. Have each member review, improve or document their assigned area and commit the actual change under their own account.
3. Use feature branches and reviewed pull requests for follow-up changes.
4. Rehearse the 10-minute deployed demo and questions.
5. Submit the public repository and deployment URLs to the course portal yourselves.

Suggested areas: Sales + transactions; Stock + products; Customers + UI; Authentication + payments + tests. These are suggested responsibilities, not completed contribution claims.
